# pw-core

PaperWhite itself: the Astro integration, the Obsidian vault loader and Markdown pipeline, SEO, i18n, the default components, the built-in **paper** theme and the `paperwhite` CLI. One package, linked into the site through the pnpm workspace.

Do not edit this folder in a blog: `paperwhite update` replaces it. Customize through `themes/`, `plugins/` and `overrides/` instead. To work on PaperWhite, see [pw-docs/contributing.md](../pw-docs/contributing.md) and [pw-docs/architecture.md](../pw-docs/architecture.md).
