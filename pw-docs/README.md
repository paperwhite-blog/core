# PaperWhite documentation

PaperWhite turns a folder of Markdown, written the Obsidian way, into a fast, SEO-complete static blog. This folder is the complete manual. It is replaced by `paperwhite update`, so keep your own notes elsewhere.

| Read this | When |
| --- | --- |
| [Getting started](getting-started.md) | You just cloned the repository. |
| [Writing](writing.md) | Frontmatter, every Obsidian syntax that renders, languages and RTL. |
| [Configuration](configuration.md) | Every option in `paperwhite.config.yaml`. |
| [Themes](themes.md) | Change the look, make a theme, share one. |
| [Plugins](plugins.md) | Install a plugin, write one, publish one. |
| [SEO](seo.md) | What is generated for you and how the audit works. |
| [Deploying](deploying.md) | GitHub Pages, Cloudflare, Netlify, Vercel, scheduled posts. |
| [Updating](updating.md) | Keep `pw-core/` current without losing anything of yours. |
| [CLI](cli.md) | Every `paperwhite` command and flag. |
| [Architecture](architecture.md) | How the code in `pw-core/` fits together. |
| [Contributing](contributing.md) | Working on PaperWhite itself. |
| [Decisions](decisions.md) | Design decisions and known limitations. |
| [Changelog](changelog.md) | What changed in each version. |

Requirements: Node 22.12 or newer and pnpm 10 (`corepack enable` gives you pnpm). Git is optional but gives you "last updated" dates and `paperwhite update`'s safety check.
