# paperwhite

```
paperwhite init [dir] [--theme paper] [--locale en,fa]
paperwhite dev | build [--strict] | preview
paperwhite check [--external] [--strict] [--json]
paperwhite new "Title" [--lang fa] [--page]
paperwhite theme add <pkg> | list | eject <Component|layouts/Name>
paperwhite import <export.xml|.zip> [--download] [--drafts] [--lang fa]
```
